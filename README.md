# Agile-Methods-Training-Creation-Testing
This is a test repository based on the [Agile Methods training repository](https://github.com/UoMResearchIT/Agile-Methods-Training-Template-Repository) as an example of how to set a repository up in advance of a training workshop.

# Immediate Set Up
The following steps will need to be performed immediately after receiving access to the new repository to complete the set up.

## Define or Link a Project
Defining and linking a Project to this repository should be performed as part of the initial setup on the course. Learners should be instructed to use the [Agile Methods Training template project](https://github.com/orgs/UoMResearchIT/projects/270/views/1) to set this up.
